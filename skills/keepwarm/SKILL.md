# keepwarm

Порядок и параметры таймера — в `C:\Users\v.pletnev\.claude\rules\keepwarm.md`. Правила нет в
контексте (сессия открыта до 22.10.2026) — прочитать файл.

- `off` — снять по разделу «Снять».
- Иначе — поставить по разделу «Поставить», в любой сессии, не только по БТ. Аргументы передать
  команде `--prompt` как есть: часы — сколько поддерживать от текущего момента (без них — до
  конца рабочего дня, внеурочно — «один прогрев»: пинг при первом простое, handoff при втором),
  `false` — без handoff в конце (по умолчанию handoff). Таймер уже есть:
  без аргументов — оставить; с аргументами — снять и поставить с новым сроком.
- `до ЧЧ:ММ` — сдвинуть конец сегодняшнего рабочего дня по разделу «Настройка дня»; свой таймер не
  трогать, если он уже есть (без часов он сам перейдёт на новый срок), иначе поставить.

Ответить одной строкой: включён (до какого времени, с handoff или без, по тексту запроса) или
выключен.
