# ai-monitor — обзор

## Что это

Локальная веб-страница (http://127.0.0.1:8770) и набор навыков для Claude Code. Через них несколько
параллельных сессий ИИ-агентов ведут свои задачи, а человек видит все задачи сразу, отвечает на
вопросы агентов и управляет приоритетами. Облака и внешних сервисов нет: всё работает на своём
компьютере, данные лежат в обычных файлах.

## Зачем

Когда агенты работают быстро и параллельно, задач становится больше, и человек теряет три вещи:
**что важнее**, **что осталось сделать**, **на каком этапе каждая задача**. Панель отвечает на все
три с одного взгляда. Заодно решены ещё три проблемы:

- вопросы агентов не тонут в чатах: они собраны в одном месте, ответ доходит до нужной сессии сам;
- новая сессия продолжает работу одной командой, без пересказа предыстории;
- параллельные сессии не мешают друг другу: видно, кто взял задачу или ресурс (базу, стенд, ветку).

## Что видно на странице

| Раздел | Что показывает |
|---|---|
| Задачи | цель, план с этапами и зависимостями, вопросы агентов, просьбы человека, документы задачи |
| Сессии | какие агенты сейчас работают и над какой задачей |
| Лимиты | расход подписки: 5 часов и неделя |
| Доска | объявления сессий друг другу (сменилась ветка, занята база и т. п.) |
| Занято | захваченные ресурсы и очередь к ним; повисший захват снимается кнопкой |
| Идеи | отложенные замыслы, отдельно от рабочих задач |

Закрытое и решённое по умолчанию скрыто, но открывается одним кликом вместе с обоснованием решения.

## Навыки и инструменты

| Навык или инструмент | Что делает | Когда срабатывает |
|---|---|---|
| **ai-monitor** (навык) | агент ведёт задачу: план, статусы, вопросы, документы — короткими командами `task.py` / `am` | при каждом решении, новом пункте плана, вопросе человеку |
| хук ответов | при вводе в сессию подсказывает агенту, что человек ответил на его вопросы; если ответов нет — молчит | каждый ввод, почти без затрат |
| **handoff** (навык) | передача работы следующей сессии: файл HANDOFF.md с состоянием, дословными словами человека, тем, что не проверено, и следующим шагом | «сделай передачку», конец дня, перед сжатием контекста |
| хуки сжатия контекста | сохраняют итог сжатия рядом с HANDOFF и напоминают сессии, где он лежит | автоматически при сжатии |
| **session-board** (навык) | доска объявлений между параллельными сессиями | при изменении общих условий: настройки, ветка, состояние базы |
| **keepwarm** (навык и хук) | держит кэш сессии тёплым при коротких паузах, после долгого простоя сам делает handoff; лишние пробуждения гасит, не обращаясь к модели | таймер раз в 30 минут; пока это проба |
| сторож вызовов (guard.py) | ловит частые ошибки агента до выполнения: секреты в выводе, push в выпускную ветку без подтверждения, общий индекс git | перед каждым вызовом инструмента |
| журнал граблей (pitfalls.py) | каждая ошибка инструмента записывается с постоянным кодом; по повторам видно, какое правило добавить в сторож | после каждого вызова инструмента |

## Почему именно так

- **Почти без токенов.** Панель, которая тратит заметную долю лимита, теряет смысл. Поэтому данные
  собирают скрипты и хуки. Модель пишет только то, что знает лишь она (цель, план, решения), короткими
  командами. Всё, что тратит токены, отключается одним переключателем, и панель продолжает работать.
- **Локально и в файлах.** Нет сервера в сети, базы данных и учётных записей. Задача — каталог с
  `task.json`, HANDOFF и вложениями. Работает без интернета, всё можно прочитать глазами.
- **Задачи вне репозиториев.** Рабочие заметки и вложения не попадают в git и не уходят вместе с кодом.
- **Только документированные интерфейсы Claude Code.** Недокументированные сведения (внутренний
  реестр сессий, токен подписки) не используются: всё, что могло нарушать условия, убрано сразу.
- **Один писатель.** Задачи меняются только через `task.py` (под замком и с проверкой), поэтому
  параллельные сессии не портят друг другу файлы.
- **Настраиваемость.** Порядок работы автора — только умолчание. Разделы — отдельные модули, их
  можно выключить в конфиге. Сломанный модуль не роняет панель.
- **Простая установка.** Python без сторонних библиотек. `install.py` ставит версию рядом с прежней
  и переключает на неё, откат — тоже переключением.

## Безопасность

Страница доступна только с этого компьютера и отвечает только своему адресу. Запросы с чужих сайтов
отклоняются. Документы открываются только из каталогов задач, HTML — в песочнице. Секреты не
выводятся. Персональные данные клиентов в задачи не пишутся (правило в навыке).
